System Definition & Architectural Identity

Addis Hiwot Attendance, Communication & Discipline Platform
Real-Time Attendance, Parent Engagement & Educational Operating System

Addis Hiwot is an institutional educational operating system engineered to digitize daily school operations, attendance verification, parent communication, and discipline workflows. It unifies School Leadership, Registrars, Teachers, Discipline Officers, and Parents across a synchronized Next.js 16 Web Application and a carrier-grade Android Native Application (Capacitor 8 + Native Java VoIP).

Operational Unification
Replaces disconnected spreadsheets, paper roll-calls, and physical binders with 5 role-tailored portals operating on a single real-time PostgreSQL database.
Offline-First Shield
Built with client-side IndexedDB caching. Teachers record attendance with zero internet; data queues safely on device and flushes automatically on reconnect.
Sub-Second Parent Loop
High-priority Firebase Cloud Messaging (FCM) alerts guardians instantly when a child is marked absent or tardy, closing the communication gap immediately.
Native Ethiopian Engine
Engineered natively for Ethiopian schools with dual ዓመተ ምሕረት (E.C.) / G.C. calendars, timezone anchoring, and complete አማርኛ (Amharic) translations.

Section 1 · Concrete Problems Solved

Solving Critical Operational Friction

Eliminating paper rosters, communication delays with parents, behavioral record fragmentation, and Western SaaS calendar mismatches.

Traditional School Challenges
  • Paper Roster Delays & Fraud: 10–15 minutes lost per period. Rosters get damaged, lost, or forged by students.
  • Disconnected Guardians: Parents only discover truancy weeks later at term-end, leading to preventable dropouts.
  • Fragmented Discipline Files: Behavioral incidents in physical binders lack evidence attachments or multi-year tracking.
  • Internet & Power Downtime: Western cloud software crashes when connectivity drops in school compounds.
The Addis Hiwot Solution
  • One-Tap Verified Attendance: Touchscreen roll-call in under 30s with GPS geofencing ensuring physical presence on campus.
  • Real-Time Parent Push Alerts: Automated high-priority alerts sound on parents' phones the exact minute a student is absent.
  • Digital Discipline Registry: Tiered severity (`Low` to `Critical`), photo evidence uploads, and verified parent signatures.
  • 100% Offline-First Engine: Works with zero connectivity; queued records flush automatically upon reconnect.

Section 4 · Android Native Architecture

Capacitor 8 + Native Java VoIP & Lock-Screen Calling

Custom Android Java services deliver carrier-grade incoming call experiences even when the phone is locked or the app is killed.

Native Java ServiceRole & Technical Capability
MyFirebaseMessagingService.java Receives high-priority data-only FCM packets; acquires WakeLock to wake sleeping devices.
CallService.java Foreground service (FOREGROUND_SERVICE_PHONE_CALL) keeping WebRTC audio pipeline alive.
IncomingCallActivity.java Native full-screen lock-screen call UI with Answer / Decline buttons and custom ringtone.
CallPlugin.java Capacitor hardware bridge managing speakerphone routing, audio focus, and SharedPreferences tokens.
Hardware GPS Geofencing
Utilizes Android ACCESS_FINE_LOCATION to calculate exact distance meters between teacher and school coordinates, preventing attendance marking off-campus.
Offline-First IndexedDB Engine
Attendance entries and messages are cached locally in IndexedDB (zetimer_messages). Background sync flushes payloads with exponential backoff.
Section 5 · Enterprise Security & Reliability

Institutional-Grade Security, Privacy & Reliability

Engineered with multi-tier encryption, zero-trust role-based authorization, tamper-proof audit trails, and resilient offline fault tolerance.

Bcrypt Password Hashing & RBAC
High-entropy salted Bcrypt hashing (cost factor 10+) ensures passwords are never stored in plaintext. Granular RBAC with cryptographic JWT authorization enforces strict zero-trust separation across all user roles.
Immutable Audit Logs
Every attendance amendment, discipline escalation, and grade promotion is stamped with user ID, timestamp, and previous state. Tamper-evident governance prevents unauthorized data alterations.
Anti-Spoof GPS Geofence
Hardware coordinates checked with tolerance radius algorithms against school boundaries. Prevents roll-call marking from off-campus locations.
Offline Fault Tolerance
Client IndexedDB stores uncommitted transactions. Sequential sync with exponential backoff guarantees zero data loss during power or telecom outages.
AES-256 & TLS 1.3 / DTLS Encryption
Military-grade AES-256 data encryption safeguards records and local storage. In-transit traffic is secured via TLS 1.3 HTTPS/WSS, with WebRTC DTLS-SRTP encrypting live voice & video streams.
Continuous Cloud Backups & HA
Automated PostgreSQL point-in-time snapshots and PgBouncer connection pooling ensure high availability, fast disaster recovery, and zero data corruption.
