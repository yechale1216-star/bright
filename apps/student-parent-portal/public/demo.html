Platform Overview

One Platform. Everything Your School Needs.

Addis Hiwot replaces scattered spreadsheets, paper registers, and phone calls with a unified, secure, mobile-first platform purpose-built for Ethiopian schools.

Multi-Tenant Architecture

Each school operates in complete isolation. All data is scoped by schoolId at the database level ? zero data leakage between tenants.

Real-Time Everything

Powered by Socket.io with a Redis adapter for multi-instance scaling. Messages, calls, notifications, and attendance updates sync instantly across all devices.

Web + Android

Built with Next.js 16 on the web and wrapped with Capacitor 8 for Android. One codebase delivers a native-quality mobile experience.

Face Recognition

Staff attendance uses on-device face descriptor matching via @vladmandic/face-api. Enrolled face vectors are stored securely, with lockout after failed attempts.

Geo-Fence Attendance

Optional GPS-based geofencing requires staff and students to check in within a configurable radius. Leaflet map integration for admin setup.

Push Notifications

Firebase Cloud Messaging delivers real-time push alerts to Android devices. Parents get instant notifications for absence, discipline cases, and announcements.

Security

Security Built In, Not Bolted On

Multi-layer security protects student data, staff records, and school communications.

JWT + HTTP-Only Cookies

Staff authentication uses short-lived JWTs in HTTP-only cookies, immune to XSS. Transparent token refresh keeps sessions alive securely.

OTP PIN for Parents

Parents authenticate via phone number and a PIN ? no password to remember. Designed for low-tech users with maximum security.

Biometric Face Recognition

Staff face check-in uses descriptor vectors, not raw photos. After configurable failed attempts, the session locks automatically.

Geo-Fence Enforcement

Attendance restricted to within a configurable GPS radius. Distance and coordinates stored per attendance record for full traceability.

Audit Logs

Every sensitive action recorded in the AuditLog table ? who did what, to which entity, and when. Old/new values stored as JSON.

Maintenance Mode

Admins toggle maintenance mode to block all API access except health checks during critical updates.
