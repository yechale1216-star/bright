🌐 Multi-Tenancy
All database queries are scoped by schoolId. A super-admin role manages school provisioning. Each school operates in complete data isolation.
⚡ Real-Time Communication
Socket.IO with Upstash Redis adapter enables broadcasting across multiple backend instances. Falls back gracefully to in-memory maps if Redis is offline.
📴 Offline-First Design
IndexedDB stores attendance records and messages locally. SyncQueue processes pending uploads with exponential backoff when connectivity is restored.
📱 Native Android
Capacitor 8 wraps the Next.js static export. Custom Java VoIP services (CallService.java, IncomingCallActivity.java) handle lock-screen call UI.
Core Features

Everything a School Needs

Six role-based portals, each tailored to specific workflows — from real-time attendance to WebRTC voice/video calls.

📋
Attendance Tracking
Teachers record daily / session-based attendance per grade, section, and stream. GPS geofencing validates location. Offline sync flushes data on reconnect. Parents receive instant FCM alerts for absent/late students.
💬
Real-Time Messaging
Full-featured chat center with DMs, group channels, reply threads, message pinning, read receipts, file attachments, and saved messages. Powered by Socket.IO with Redis pub/sub for horizontal scaling.
📞
VoIP Voice & Video Calls
Peer-to-peer WebRTC audio/video calls with ICE/SDP negotiation via Socket.IO signaling. Data-only FCM wakes backgrounded Android devices. Native Java IncomingCallActivity shows lock-screen call UI.
⚖️
Discipline Management
Full incident lifecycle — severity levels (LOW → CRITICAL), evidence attachments, witness statements, follow-up actions, and parent notification status. Dedicated Discipline Officer portal.
👨‍👩‍👧
Parent Portal
Parents log in via phone + PIN (OTP-style). View attendance history, receive push notifications, read discipline reports, and message school staff through the messaging center.
📊
Analytics & Reports
Admin dashboard with Recharts-powered charts: attendance by grade/section/date range, discipline incident trends, teacher assignment coverage. CSV/PDF export. Academic year management with term/semester tracking.
👩‍🏫
Teacher Management
Assign teachers to grades, sections, and subjects. Manage timetables. Teachers see their class rosters, take attendance, and communicate with parents and admin.
🎓
Student Management
Bulk CSV import with preview, individual student profiles, grade/section/stream enrollment, and parent-student linking. Year-end promotion workflow moves students to next grade.
🌍
Bi-Lingual + Ethiopian Calendar
Complete Amharic (አማርኛ) and English translations across all portals via custom i18n engine. Ethiopian Calendar support with timezone-anchored date formatting (Africa/Addis_Ababa), Amharic month/day names.

Security

Defense-in-Depth Security Model

Multiple layers of security from password hashing to role-based access control, CORS, rate limiting, and security HTTP headers.

✅ Implemented Measures
🔐
Password Hashing
bcryptjs with salt rounds 10. Plaintext passwords never stored or logged.
🎟️
JWT Authentication
HS256 signed tokens stored in HTTP-only, SameSite=Lax cookies with Secure flag in production.
🛡️
Role-Based Access Control (RBAC)
Every API endpoint protected by authMiddleware + authorize([roles]) middleware chain.
⛔
Rate Limiting
Login: 10/min · Password reset: 3/min · OTP: 5/15min — all per IP.
🔒
Security HTTP Headers
X-Content-Type-Options, X-Frame-Options: DENY, X-XSS-Protection, Referrer-Policy set on all responses.
✅
Input Validation
Zod schemas validate all critical auth and registration payloads server-side.
🏫
School-Scoped Data Isolation
Every service query includes schoolId filter. Cross-school data leakage is architecturally impossible at the ORM layer.
⚠️ Known Issues (Pre-Handover)
🔴 Critical — Hardcoded JWT Fallback
server/src/utils/jwt.ts contains a predictable fallback secret. Server must crash on startup if JWT_SECRET is missing.
🔴 Critical — Keystore Credentials on Disk
android/keystore.properties stores raw signing passwords. Must be added to .gitignore and supplied via CI/CD secrets.
🔴 Critical — Destructive Build Command
render.yaml runs prisma db push --accept-data-loss on deploy. Must be changed to prisma migrate deploy.
🟡 High — Hardcoded Test Seed Account
Seed SQL script contains a known admin account with password: 123456. Must NOT be run in production.
Recommended Improvements
→ Redis-backed JWT blacklist for token revocation on logout
→ TOTP two-factor authentication for admin accounts
→ Supabase Row Level Security (RLS) policies
